# Work tracker

What it does: an Excel macro (Tracker.bas) that keeps everything you are
tracking at work in one list, with a dated log of every update and
reminders that pop up while the file is open. Any row can repeat and any
row can remind; closing a repeating row makes the next one. v2, posted
Oct 6, 2026; 105 checks. pictures/ shows the four sheets.

At work: new blank workbook, paste Tracker.bas, save as .xlsm, run it
once; it makes the sheets. Import old with the old tracker open brings v1's
rows across. Leave it open all day for the reminders; the notes at the top
of the macro say how to put it in Startup.

Open: the first day on v2 at work (popup over other windows, the Startup
shortcut, Import old on the real v1 file). Then v1 is retired.
