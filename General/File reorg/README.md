# File reorg

What it does: maps a shared drive before a reorg. ListShareFolders.bas
writes a share's folder tree to a text file on the desktop (names only,
never opens a file).

At work: blank workbook, Alt F11, Insert, Module, paste ListShareFolders
.bas, set SHARE_PATH, press F5. Run it again before the reorg starts so
the plan works from a fresh listing.
