# File reorg

What it does: maps a shared drive before a reorg. ListShareFolders.bas
writes a share's folder tree to a text file on the desktop (names only,
never opens a file).

Setup: blank workbook, Alt F11, File, Import File, pick
ListShareFolders.bas, set SHARE_PATH, press F5. Run it again right before the
reorg starts, for a fresh listing.
