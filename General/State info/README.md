# State info

What it does: one workbook (State Info.xlsx) in place of the three old
state workbooks: one list per kind of info (states, returns, licenses,
rates, contacts, tax setups), every row tied to a state by its
two-letter code, and a State page that shows one state from every list
at once. Georgia is filled in as an example, public facts only. The
preview folder has pictures of the State page.

Setup: download State Info.xlsx and type our own details into its lists.

Open: the tax setups columns are a first guess.
