# State info

What it does: one workbook (State Info.xlsx, built by build_workbook.py)
to replace the department's three binder-style state workbooks: one list
per kind of info (states, returns, licenses, rates, contacts, tax setups),
every row tied to a state by its two-letter code, and a State page that
shows one state from every list at once. Georgia is filled in as the
worked example, public facts only. recalc.py recalculates and strips
author details; render_preview.py makes the pictures in preview/.

At work: download State Info.xlsx and type the company's own facts into
its lists. Not posted yet.

Open: a look-over (preview/ has the pictures), then it ships. Which
Excel the work PC has (File, then Account). The tax setups columns are a
first guess.
