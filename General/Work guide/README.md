# Work guide

What it does: one page, Work guide.html, with the house rules for work:
where each thing lives, how a doc and an email look, how to cite, and how
a state's how-to-file doc is written. It ends with the email to copy and
the cite for each state's tax law.

At work: download Work guide.html and open it in the browser. To copy a
part into Word or Outlook, select it and paste.

Open: Work Notes.xlsx needs its Open questions tab. State regulations
have no cite list yet.
