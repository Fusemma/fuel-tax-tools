# Missouri use tax workbook

What it does: the quarterly Missouri use tax worksheet, MO Use Tax
Workbook - BLANK.xlsx. Paste the month's TERSE sales report and AR sales
taxes by county report on their tabs and the RECAP tab adds up the
month and the quarter: total sales, exempt sales, taxable sales and
sales due by county and rate, the county list for the return with NO
LOCAL on the 4.225% lines, and sales with no local tax. One light on
the READ ME tab says whether the month checks out; when it is red it
says what is wrong. It turns red, instead of leaving lines out without
a word, when a report runs past the gray columns at the right of its
tab, when those gray columns are gone after a whole-sheet paste, when a
cell shows an error like #N/A, and when a line's product type isn't on
LISTS. Plain formulas, no macro, any Excel from 2010 on.

Setup: download MO Use Tax Workbook - BLANK.xlsx, save a copy for the
quarter, and type the quarter's first day on READ ME. The how-to is on
READ ME beside the light. The county and rate list on the LISTS tab
starts with the counties and rates from the 3rd quarter 2026 worksheet;
add a pair there when the light asks for one. The product types on
LISTS start with all 40 of the system's types, each with Yes or No
under Counts in sales.

Each month: paste the TERSE and the AR report on that month's tabs, the
way READ ME says. If the light says the gray columns are gone and the
file is already saved, copy them over from another month's tab in this
file; the light says which tab and which columns. Start again from the
blank only if no month's tab still has them.

Open: jurisdiction codes are on the list for two counties only; type the
rest on LISTS as they come up. When a product type shows up that isn't
on LISTS, add it there in the first empty yellow row, then tell whoever
keeps this workbook, so the next copy comes with it.
