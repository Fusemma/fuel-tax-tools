# Missouri use tax workbook

What it does: the quarterly Missouri use tax worksheet, MO Use Tax
Workbook - BLANK.xlsx. Paste the month's TERSE sales report and AR sales
taxes by county report on their tabs and the RECAP tab adds up the
month and the quarter: total sales, exempt sales, taxable sales and
sales due by county and rate, the county list for the return with each
line's jurisdiction code and NO LOCAL on the 4.225% lines, and sales
with no local tax. The county and rate lines build themselves on the
LISTS tab from the AR report's Tax Paid lines, each county and rate
once, lowest rate first and A to Z within a rate. Nothing is typed for
them, and a county new this quarter takes its place in that order by
itself. One light on the READ ME tab says whether the month checks out;
when it is red it says what is wrong and where. It turns red, instead
of leaving lines out without a word, when a line has no jurisdiction
code, when an AR line's county isn't one of Missouri's 114 counties or
St. Louis City, when an AR line's Tax Rate isn't a rate, when a report
runs past the gray columns at the right of its tab or those gray
columns are gone or have a gap, when lines from an earlier paste are
left under a report, when something is typed where the lines fill in,
when a cell shows an error like #N/A, and when a line's product type
isn't on LISTS. No macro. Needs Microsoft 365 Excel: the lines use its
newer formulas, like UNIQUE, SORT and FILTER.

Setup, once a quarter: download MO Use Tax Workbook - BLANK.xlsx, save
a copy for the quarter, and type the quarter's first day on READ ME.
Then bring last quarter's jurisdiction codes over: open last quarter's
file, go to its LISTS tab, click F2, hold Shift and click G61, press
Ctrl C. Come back to the new file, click LISTS F2, press Ctrl V. Skip
this if last quarter's file has no yellow table headed "Line, as column
A shows it". The how-to is on READ ME beside the light. The product
types on LISTS start with all 40 of the system's types, each with Yes
or No under Counts in sales.

Each month: paste the TERSE and the AR report on that month's tabs, the
way READ ME says. When a line has no jurisdiction code, the light names
it and the cell to type in: type the line as LISTS column A shows it,
and its code, in the yellow code table on LISTS (columns F and G). It
is typed once and stays. Lines at 4.225%, marked NO LOCAL, need no
code. If the light says the gray columns are gone or have a gap and the
file is already saved, copy them over from another month's tab in this
file; the light says which tab and which columns. Start again from the
blank only if no month's tab still has them.

Open: the blank comes with three jurisdiction codes, Nodaway 6.1%,
Stoddard 6.225% and Clay 9.725%. When you add a code at work, tell
whoever keeps this workbook, so the next copy comes with it. When a
product type shows up that isn't on LISTS, add it there in the first
empty yellow row, then tell whoever keeps this workbook, so the next
copy comes with it. The county check reads a county with or without
periods, with COUNTY or CO at the end, and with SAINT spelled out; if
the light says a real Missouri county isn't one, tell whoever keeps
this workbook.
