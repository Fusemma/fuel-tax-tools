# California rates check

What it does: an Excel macro (CARates.bas) that reads the CDTFA's
quarterly rates spreadsheet and shows what changed in the city and county
sales and use tax rates. It makes its own How to use tab.

Setup: bring CARates.bas into a new workbook (Alt F11, File, Import
File), save as CA Rates Check.xlsm, and run CheckCaliforniaRates once. It
makes the sheets and the button and asks for the rates file. Load October's
list first as the baseline. Use the .xlsx, not the old .xls. The January 1,
2027 list should post December 1, 2026.
